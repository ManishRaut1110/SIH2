Disaster Aggregation System

Overview

The Disaster Aggregation System is a Streamlit-based web application designed to visualize and analyze disaster-related tweets. It connects to a MongoDB database, extracts relevant disaster-related data, and presents it in an interactive dashboard with charts, a dataset explorer, and a heatmap for geographical analysis.

Features

Dashboard: Provides insights into disaster-related tweets, including relevance distribution and categorical labels.

Dataset Explorer: Paginated view of tweets with details such as relevance, labels, and locations.

Heatmap: Interactive map displaying disaster occurrences based on extracted locations.

About Us: Section detailing the project and its contributors.

Technologies Used

Frontend: Streamlit for UI components

Backend: Python, Pandas, Plotly, Folium, and Geopy

Database: MongoDB

Visualization: Plotly for graphs and Folium for maps

Usage

Select a section from the sidebar:

Dashboard: View charts and insights.

Dataset: Browse tweet data with pagination.

Heatmap: Select disaster types and view affected locations.

About Us: Learn more about the project.

Interact with visualizations and explore disaster trends.
